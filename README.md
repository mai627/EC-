## ECサイトの売上分析と改善案

ネット上のECサイトの売り上げのサンプルデータを使用し、SQLでの前処理とPythonでの可視化までを行い、ビジネス改善提案をまとめたプロジェクトです。

## 目的

売上の傾向を特定し、在庫管理とマーケティング戦略の最適化を図るため。

## 技術

・言語：SQL、Python
・ライブラリ：Pandas, Matplotlib
・ツール：DBeaver

## データ処理のプロセス

1. SQLによるデータクレンジング

データの整合性を確認したところ、以下の3項目のデータの異常値が確認されました。

・UnitPrice（単価）が0未満：サンプル、販促プレゼント、調整と考えられる。

・CustomerIdなし：ゲストによる購入、またはシステム上の記録漏れと考えられる。

・Quantity（数量）が0未満：InvoiceNoの頭文字が’C'の場合は商品のキャンセルと考えられる。
　通常のキャンセル処理（InvoiceNoの頭文字が’C'）以外にも、
　数量（Quantity）がマイナスのレコードが10,624件存在することを発見しました。
	【特徴】
	・多くの場合、Descriptionが欠損している。
	・UnitPriceが0で得ある。
	・顧客IDが紐づいていない。
　これらのデータは、システム上の管理レコードであると推測しました。	

上記は、顧客の購買行動分析に適さないため、SQLで除外しました。

2. Pythonによるデータの可視化

SQLでクレンジングしたデータを読み込み、以下の3つの観点でデータを可視化しました。

・国別の売り上げ
・月別の売り上げ
・商品別の売上TOP30

商品数は数が膨大になるため、TOP30を可視化しました。
国別の売上の上位の割合はSQLで計算しました。

## 結果と考察

・国別の売り上げ
United Kingdom（イギリス）の売上が全体の86.4%を占めている。
イギリス向けのプロモーションに効果があると考えられる。

・月別の売り上げ
11月の売上が最大。次いで12月の売上が多い。
ホリデーシーズンに向けての在庫管理やプロモーションが必要。

・商品別の売上TOP30
上位には、PAPER CRAFT（ペーパークラフト）、CAKESTAND（ケーキスタンド）、HEART T-LIGHT HOLDER（キャンドルホルダー）など、
ホームパーティーや装飾雑貨が占めていることから、本サイトの顧客層はイベント目的のユーザーであると推測される。
クリスマスなどのイベントに向けた施策や、ユーザーの誕生日に向けたプロモーションが有効であると考えられる。

## 苦労した点

【課題】
最初は、データのクレンジングからPythonで行っていましたが、コードが少し多くなってしまいました。

【解決策】
調べたところ、SQLでデータの処理をして、それをPythonで読み込んで可視化のみPythonで行う方が
処理速度と可読性の観点で優れているとのことでしたので、データの処理と可視化の役割を分けました。
実務においても、この「DB側で極力処理を済ませる」設計が重要であると学びました。
